# AI Wiki 技术栈推荐

## 一、总体架构概述

AI Wiki 采用 **完全离线架构**：

-   所有数据预打包在客户端
-   无网络请求
-   无远程依赖
-   无第三方 SDK

推荐架构：

-   架构模式：MVVM
-   分层结构：UI 层 / ViewModel 层 / Repository 层 / 数据层
-   数据源：本地 SQLite（支持全文检索 FTS）
-   用户偏好：本地 Key-Value 存储
-   主题系统：系统主题 + 手动切换

设计目标：

-   简单
-   稳定
-   可维护 5 年以上
-   易扩展
-   易重构

# 二、iOS 技术栈

## 2.1 开发语言

-   Swift（最新稳定版本）

理由： - 类型安全 - 现代语法 - 官方长期支持 - 与 SwiftUI 深度集成

------------------------------------------------------------------------

## 2.2 UI 框架

-   SwiftUI

优势： - 声明式 UI - 代码量少 - 自动状态驱动刷新 - 原生支持深色模式

------------------------------------------------------------------------

## 2.3 架构

-   MVVM
-   使用 ObservableObject + @StateObject
-   使用 async/await 处理异步

推荐结构：

App ├── Features ├── Core ├── Data └── UIComponents

------------------------------------------------------------------------

## 2.4 数据存储

推荐方案：

### 主方案（推荐）

-   SQLite + FTS5

理由： - 本地全文搜索性能高 - 数据结构清晰 - 可控性强 - 无黑盒

### 轻量方案

-   本地 JSON + 内存索引

------------------------------------------------------------------------

## 2.5 本地存储

-   UserDefaults（保存主题和设置）
-   SQLite（保存收藏 ID）

------------------------------------------------------------------------

## 2.6 主题系统

-   使用 ColorScheme
-   支持：
    -   跟随系统
    -   强制浅色
    -   强制深色

------------------------------------------------------------------------

# 三、Android 技术栈

## 3.1 开发语言

-   Kotlin

优势： - 空安全 - 协程支持 - 官方推荐

------------------------------------------------------------------------

## 3.2 UI 框架

-   Jetpack Compose

优势： - 声明式 UI - 与 MVVM 天然契合 - 内置 Material 3 -
深色模式支持完善

------------------------------------------------------------------------

## 3.3 架构

-   MVVM
-   ViewModel
-   StateFlow
-   单 Activity + Navigation Compose

------------------------------------------------------------------------

## 3.4 数据存储

推荐方案：

### 主方案（推荐）

-   Room + SQLite FTS

优势： - 类型安全 - 官方维护 - 支持数据库迁移

------------------------------------------------------------------------

## 3.5 本地存储

-   DataStore（保存主题等偏好）
-   Room（保存收藏 ID）

------------------------------------------------------------------------

## 3.6 主题系统

-   MaterialTheme
-   动态支持 Light / Dark
-   支持系统跟随

------------------------------------------------------------------------
